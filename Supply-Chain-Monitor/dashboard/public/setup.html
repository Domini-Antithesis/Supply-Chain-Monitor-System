Supply Chain Monitor

First-run setup

Setup has already been completed. Configuration lives in .env. To change it, edit that file directly and restart with docker compose up -d. Go to the dashboard.

Let's get you connected

This system reads the news for your suppliers, has an AI grade the disruption risk, and alerts you when something serious appears. To do that it needs accounts on a few free services — each one is linked below with what to click.

Your keys are written to a local .env file on this machine only. They are never uploaded anywhere, never committed to source control, and never sent to your browser again after saving.

1

Choose your login

You'll use this to sign in to the workflow engine at localhost:5678. Make it up now — the account is created for you automatically.

2

NewsAPI — where the news comes from

Register free at newsapi.org/register. Your key appears on screen right after signing up. The free tier works on localhost, which is where this runs.

3

Groq — the AI that reads the articles

Sign in at console.groq.com/keys and click Create API Key. Copy it immediately — Groq shows it only once.

4

Airtable — where findings are stored

Two things here. First, create an empty base at airtable.com — leave it completely empty, the tables get built for you. Its ID is the appXXXXXXXX part of the URL while the base is open.

Second, create a token at airtable.com/create/tokens. Add your new base under Access, and tick these four scopes: data.records:read, data.records:write, schema.bases:read, schema.bases:write. The schema ones are what let it build the tables — it's the step people most often miss.

5

Slack — where urgent alerts land

Follow Slack's incoming webhook guide: create an app, enable Incoming Webhooks, then Add New Webhook to Workspace and pick the channel alerts should go to. Copy the URL it gives you.

6

Email alerts

Where should alert emails go, and which mailbox sends them? For Gmail use smtp.gmail.com port 587 with an app password — a normal account password will not work.

The SMTP fields are optional. Leave them blank to run Slack-only.

Configuration saved

Your keys were written to .env. One last step to bring everything online:

docker compose up -d

Run that in the Supply-Chain-Monitor folder. If you started this with start.ps1 or start.sh, it is already happening automatically — just wait a moment. Setup then creates your account, builds the Airtable tables, and switches both workflows on.
